## 怎么判断一台 VPS 是否符合 CN2 GT 需求

购买前可以按下面顺序核查，避免只看商品标题：

1. **确认产品名称。** 页面写 CN2 GT、CN2 GIA 还是普通线路？“CN2 优化”这种宽泛描述不足以说明具体线路。
2. **确认测试 IP 和路由。** 使用服务商提供的测试 IP，从自己常用的电信、联通或移动网络检查去程和回程。只测一个方向，可能漏掉另一段绕路。
3. **在实际使用时段测试。** 如果服务器主要用于国内用户访问，晚间高峰期的表现比工作日白天的一次测速更有参考意义。
4. **对照资源限制。** 流量、端口速率、内存、CPU 和存储都可能成为瓶颈。线路再合适，流量超限或配置不够也解决不了业务问题。
5. **核对退款和迁移规则。** VPS 属于自主管理服务，购买前应看清退款期限、可迁移机房范围及迁移是否影响现有 IP。

Traceroute 或 MTR 可以帮助观察路径和丢包位置，但路由节点名称、IP 段和单次结果都需要结合运营商及测试时间解释。不要只凭某个节点数字就下最终结论。
